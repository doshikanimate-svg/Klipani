# KLIPANI — план разработки

## Принципы

Проект запускается локально на macOS/Apple Silicon без обязательных облачных API. Каждый этап должен оставлять рабочее приложение. Первый релиз использует SQLite, FFmpeg и детерминированный mock-анализ, поэтому интерфейс и видеоконвейер можно проверить до установки Whisper или локальной LLM.

## Технические решения P0/P1

- Frontend: Next.js App Router, TypeScript, Tailwind CSS.
- Backend: FastAPI, SQLAlchemy-free SQLite; фон jobs — in-process background threads (без внешнего брокера).
- Видео: только сформированные Python-кодом FFmpeg/ffprobe команды; LLM не управляет shell-командами.
- Хранилище: `storage/{uploads,working,clips,thumbnails,transcripts}`; метаданные в `storage/klipani.db`.
- LLM: `LLM_PROVIDER=mock|ollama`; при недоступности Ollama — fallback на Mock.
- Whisper: optional; при ошибке транскрипции анализ продолжается duration/mock-путём.
